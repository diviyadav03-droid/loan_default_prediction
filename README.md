# Loan Default Prediction

A machine learning capstone project exploring loan default prediction using 5,960 home equity applications.

## Project overview

This project compares Logistic Regression, Decision Tree, Random Forest, and tuned XGBoost models. It also examines missing data, outliers, model evaluation, and responsible use of machine learning in credit risk.

## Results

In the reported test results, tuned XGBoost achieved:

- Recall: 0.798
- Precision: 0.764
- F1 score: 0.781
- ROC-AUC: 0.950

These results are from this project’s evaluation and should not be interpreted as a guarantee of real-world performance.

## Responsible use

This is an educational project, not a production credit decision system. Model performance, fairness, data quality, and applicable lending requirements need careful review before any real-world use.
